# Public Assets Directory

## Purpose

Hold public static assets for the SLC Intelligence web application.

## Status

Status: Active

Last updated: 2026-07-28

Owner: Product Owner

## Layout

| Path | Use |
| --- | --- |
| `brand/slc-logo.png` | Official logo (source of truth raster) |
| `brand/slc-logo.svg` | Official logo vector companion |
| `brand/slc-logo-512.png` | High-resolution mark |
| `icons/` | Favicon and PWA icons |
| `site.webmanifest` | Web app manifest using brand colors |

## Rules

1. Do not redesign or reinterpret the official SLC logo.
2. Maintain logo proportions, spacing, and colors.
3. Do not place student photos or real educational records here.
4. Prefer accessible alternatives (`alt` text / visually hidden labels) when rendering logos.
