# Behavior Detective

Phase 10 implements observable behavior definitions, examples, nonexamples, replacement behaviors, direct observation sessions, measurement-specific observation tables, status history, corrections, and intensity scales.

## Application surface

- `/behavior-detective`
- `/students/[studentId]/behavior`
- `/students/[studentId]/behavior/definitions`
- `/students/[studentId]/behavior/definitions/[behaviorId]`
- `/students/[studentId]/behavior/observations`
- `/students/[studentId]/behavior/observations/new`
- `/students/[studentId]/behavior/analytics`
- `/students/[studentId]/behavior/fba-support`

## Measurement methods

Supported rows include ABC, frequency, duration, latency, interval, and intensity. Raw entries are preserved; derived values are deterministic display helpers.

## Guardrails

Behavior Detective organizes observations. It does not diagnose, identify a function as fact, or make disciplinary/placement/service decisions.
