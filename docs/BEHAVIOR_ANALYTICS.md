# Behavior Analytics

Phase 11 adds deterministic behavior analytics helpers and FBA evidence workspace support.

## Implemented calculations

- Rate per minute
- Duration average and median
- Latency average and median
- Interval percentage
- Intensity distribution
- Time-of-day grouping
- Day-of-week grouping
- Setting and activity grouping
- ABC antecedent/consequence category counts
- Replacement behavior rate
- Trend
- Moving average
- Phase comparison
- Data sufficiency status

## Visualization approach

Application pages prefer accessible tables, readiness panels, and text summaries. Heavy charting libraries are not introduced in this phase.

## Interpretation

Calculations describe recorded data in the selected scope. Phase comparisons and patterns do not establish cause.
