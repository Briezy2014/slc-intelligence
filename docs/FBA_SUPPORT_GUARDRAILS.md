# FBA Support Guardrails

FBA support workspaces organize evidence and team-authored hypotheses. They do not independently determine behavior function.

## Allowed

1. Link behavior sessions, ABC rows, measurement-specific observations, and analytics ranges.
2. Show category counts and context groupings as descriptive summaries.
3. Store educator/team hypothesis text.
4. Show data sufficiency and readiness notes.

## Prohibited

1. Stating that a context caused behavior.
2. Stating a behavior function as a system conclusion.
3. Producing disciplinary, placement, eligibility, or service decisions.
4. Presenting system text as final without educator review.

## Required wording pattern

Use observational wording such as: "Within the selected records, most coded ABC entries were associated with task-demand categories." Avoid cause or diagnostic wording.
