# SOP — Instructional Intelligence

Use this page for IEP/instruction drafting aids. Every output needs educator review before it goes into an IEP, progress report, or family letter.

## Pilot rules

- Use coded student IDs only (for example S1–S7).
- Do not paste real names, birthdates, addresses, or other PII.
- Tools draft and flag; they do not decide eligibility, placement, or legal compliance.

## Daily workflow

1. **Command Center** — day schedule, routines, missing-data signals.
2. **Students / Rapid Progress / Goals** — enter and review classroom data.
3. **Instructional Intelligence → Tools** — draft or check IEP language.
4. **Family Communication** — send home-ready language after review.
5. **IEP / ETR Docs** — place reviewed language into district document drafts.

## Tools on this page

| Tool | What it does | How to run |
| --- | --- | --- |
| Present levels | Drafts PLAAFP structure from evidence | Paste coded evidence → Draft |
| Goal–need match | Surfaces coverage gaps | Needs (one per line) → Match |
| Measurable goal check | Flags vague / incomplete goals | Paste goal → Check |
| Consistency check | Compares ETR / IEP / progress excerpts | Paste excerpts → Run |
| Parent-friendly | Rewrites jargon for families | Paste technical text → Generate |
| Instructional plan | I do / We do / You do from a goal | Paste goal → Create |
| Para supports | Do/don’t language for approved supports | One support per line → Explain |
| Meeting prep | Strengths, needs, progress, family questions | Fill fields → Generate |

Each tool also has a **Fill demo sample** button for district walkthroughs.
