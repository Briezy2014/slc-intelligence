# Known Risks

1. Remote Supabase may be unconfigured; protected pages intentionally show configuration notices.
2. RLS tests need expansion before production readiness.
3. Server actions return safe generic errors; richer field-level server feedback may be added later.
4. Rapid progress entry uses a broad progressive-enhancement form; a later UX pass should tailor fields dynamically by measurement type.
5. Analytics are descriptive only and require product/legal/statistical review before any decision-support expansion.
6. No production compliance certification is claimed.
7. Phase 9 progress-report drafting is not implemented.
