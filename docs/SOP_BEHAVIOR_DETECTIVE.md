# SOP — Behavior Detective

**Audience:** Classroom teachers, intervention specialists, paraprofessionals  
**Path:** Behavior Detective (`/behavior-detective`) or a student’s Behavior tab  
**Pilot rule:** Use coded student IDs only (S1–S7). Do not enter real names unless district/legal approval allows it.

## Everyday use (3 steps)

1. Choose the student.
2. Choose the behavior from the dropdown (common classroom behaviors are created automatically).
3. Record what you saw, then save.

### What are you recording today?

| Choice                                  | Meaning                                 |
| --------------------------------------- | --------------------------------------- |
| What happened before, during, and after | Everyday notes: before → during → after |
| How many times it happened              | Count while you watched                 |
| How long it lasted                      | Total minutes / episodes                |

Advanced options (timer intervals, intensity scales, latency) stay hidden unless you open them.

## If the behavior list is empty

Click **Set up common classroom behaviors**, or use **Add another starter…** to save one starter immediately.

Common auto-created starters include: Task refusal, Work avoidance / stalling, Calling out, Elopement from assigned area, Verbal disruption, Flopping, Bolting during transition, Delayed compliance.

## Custom wording

Open **Need a custom behavior?** to edit starter wording or add a new behavior name.
